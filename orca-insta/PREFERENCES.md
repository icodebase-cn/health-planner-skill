# OrcaInsta 用户设计偏好

> 本文件记录 Bos 的视觉偏好，与 guide.md 参考标准合并使用。
> guide.md 提供默认体系，本文件记录偏离默认的 Bos 个人口味。
> 调整前先读本文件，再读 guide.md。

---

## 杂志分页

| 参数 | Bos 偏好 | 参考默认 |
|------|---------|---------|
| 配色 | **冷高对比**：纯黑 `#000` + 纯白 `#fff`，不用暖灰 | #FAFAF8 冷白 |
| 正文 | **24px**，line-height 2.0 | 22px |
| H1 | **48px**，font-weight 600 | 44px |
| 分割线 | **1px 纯黑**，不用灰 | #e8e6e0 |
| 引用 | 左边框 2px 纯黑，无背景 | #f2efe9 底 |

---

## 文章模式（长图）

| 参数 | Bos 偏好 | 说明 |
|------|---------|------|
| 画布宽 | 1080px | 固定 |
| 左右边距 | **24px**（每侧）| 手机友好，10-30px 范围 |
| 内容区宽 | ≈ **1032px** | 1080 - 24×2 |
| 正文字号 | **32px** | 最小 16sp × 2x 缩放 |
| 行高 | **2.2** | ≥1.8 |
| H2 字 | **36px** | font-weight 600 |
| H2 左边框 | **3px solid #000** | 高对比冷黑，非暖橙 |

> 文章模式暖白底 `#f8f4e9` 保留，但强调色应向高对比靠拢。
