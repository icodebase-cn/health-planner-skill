# OrcaInsta 设计品味准则

orca-insta 所有视觉输出必须经过本准则校验。

---

## 硬约束（不可偏离）

| # | 约束 | 说明 |
|---|------|------|
| H1 | 杂志分页固定宽高 | **宽 1080px，高 1440px**（3:4，适合小红书） |
| H2 | 杂志长图/文章固定宽度 | **宽 1080px，高度无限**，fullpage 自动截图 |
| H3 | 正文行间距禁止过低 | 大面积正文**禁用行高 < 1.8** |
| H4 | 禁止纯黑 #000000 | 所有文字色、边框色、分割线**严禁**使用纯黑 `#000000`，一律用 `#1a1a1a` 或更浅的深灰（`#333333`/`#555555`）。例外：仅在「冷·高对比·极简」风格意图下，H1 标题和特殊强调元素可使用 `#000000`。文章模式正文和正文段落**永远禁止**使用纯黑。 |

| 模式 | 风格 | 定位 |
|------|------|------|
| **杂志分页** | 冷·低对比·松·极简 | 清冷现代简约，衬线体 |
| **杂志长图** | 冷·低对比·松·极简 | 同杂志，无限高单页，舒适边距 48–72px |
| **文章模式** | 暖·低对比·**松**·极简 | GitHub风技术文档，轻松易读，无衬线，舒适边距 48–72px |

## 字体规则

| 模式 | 主字体 | 备注 |
|------|--------|------|
| 杂志（分页/长图）| **衬线**：Noto Serif SC / Source Han Serif | 冷调、文艺感 |
| 文章模式 | **无衬线**：Noto Sans SC / PingFang SC | 轻松易读 |

**禁止**：Inter 字体；衬线与无衬线混用主字体（≤5% 偶有点缀除外）。

## 边距与节奏 — 宽松约束（自然法则）

边距没有绝对值，只有**相对安全区间**：

| 场景 | 最小值 | 舒适值 | 最大值 |
|------|--------|--------|--------|
| 杂志长图左右边距 | 48px | **56–72px** | 96px |
| 文章模式左右边距 | 48px | **56–72px**（当前模板值 48px） | 96px |
| 杂志分页边距 | 36px | 48–64px | 80px（当前模板值 68px） |

**宽松约束规则**：
- 边距应在舒适区间内**偏大**，不要偏小（偏小会显得挤）
- 正文区宽度 = 页面宽度 − 2×边距，**永远不要**为了多放内容而缩小边距
- 图片区宽度可以顶到页面边缘（边距=0），正文内容区不行
- 当模板固定 body width 时，边距用 `padding: 0 Xpx` 精确控制

## 字号体系

| 模式 | 基准字号 | 字号比例 |
|------|---------|---------|
| 杂志（分页/长图）| 正文字号 **34px**（`--BASESIZE`） | 1.333（Perfect Fourth） |
| 文章模式 | 正文字号 **34px**（`--BASESIZE`，手机 2x 缩放后 ≥17sp） | 1.25（Major Third） |

### 字号比例指南（v0.3 数学秩序）

字号以等比数列推导，从 BASESIZE 起逐层递进。常用比例体系：

| 体系 | 比例 | 适用场景 |
|------|------|---------|
| Perfect Fourth | **1.333** | 杂志（分页/长图） |
| Major Third | **1.25** | 文章模式 |

**推导规则**（以 Perfect Fourth 为例，BASESIZE=34px）：

| 元素 | 比例系数 | 绝对值 |
|------|---------|--------|
| H1（主标题）| × 1.333³ ≈ × 2.37 | ≈ 60px |
| H2（章节标题）| × 1.333² ≈ × 1.78 | ≈ 45px |
| H3（子节标题）| × 1.333 | ≈ 34px |
| 正文（p）| × 1.0（基准） | 34px |
| eyebrow / 标签 | ≤ × 0.4 | ≤ 14px |

> ⚠️ **比例体系为软约束**。1.333 系列在正文 34px 时 H1 达到 60px，实际视觉上偏大；可按风格意图在 1.25–1.333 之间选择合适比例，保持 H1 > H2 > H3 > 正文 的层级递减关系即可。

**行高规则**：
- 杂志：行高 **2.0**，段间距 **> 行高**
- 文章：行高 **≥1.8**，推荐 **2.0–2.2**

## 配色系统

### 杂志模式（冷调）
```
bg        #FAFAF8  冷白
text      #1a1a1a  近黑（非纯黑）
muted     #888888  灰色标签/来源
accent    #（不用或极少）
surface   #f2efe9  引用块/卡片底
border    #e0ddd5  分割线
```

### 文章模式（暖调）
```
bg        #fffdf8  暖白
text      #3a3020  深棕（暖色系，非冷灰）
text-hard #1a1008  近黑（用于标题、H2 左边框）
muted     #7a7060  浅灰标签
surface   #f3ede0  引用块底
border    #d8cfc0  分割线
```

### 灰色规则
绝大多数场景用 **1–3% 饱和度**的深灰，非纯黑。
例外：冷·高对比·极简 风格意图下，纯黑纯白是正确选项。

### 对齐与缩进规则

| 规则 | 说明 |
|------|------|
| **列表左侧缩进** | 列表比正文整体向右缩进（`padding-left`），bullet/marker 收进正文范围内；正文左边界是所有内容的左限，换行文字应与正文对齐。 |
| **H2 左边框** | 边框从内容区左边界开始，16px padding 计入内容区宽度 |
| **所有文字左对齐** | 正文段落、列表项、引用块**全部** `text-align: left`，禁止居中布局（除特殊视觉中心元素如 hero 图） |
| **引言块不缩进** | `blockquote` 宽度撑满内容区，**禁止**额外 `margin-left/right` 缩进 |

**视觉对齐自检**：生成后检查 — 列表项文字是否与段落文字在同一垂直线上？H2 边框是否与左侧内容区边界对齐？

## AI 生成禁忌

- **禁止**：Inter 字体、紫蓝渐变、纯黑文字（`#000000`），除非风格意图明确要求（冷·高对比·极简 场景下 H1 可用）
- **禁止**：三等分卡片、居中 Hero（DESIGN_VARIANCE > 4 时）
- **禁止**：`box-shadow` 外发光，用内边框或染色阴影替代
- **禁止**：AI 文案腔（「赋能」「无缝」「释放」「下一代」）
- **禁止**：行高 < 1.8（正文大面积区域）
- **禁止**：列表项 `margin-left` 或额外缩进导致文字与正文不对齐

## 出厂自检

生成截图前，逐项确认：

- [ ] 杂志分页宽高 = 1080×1440px？
- [ ] 杂志长图/文章宽 = 1080px，高度无限（fullpage）？
- [ ] 杂志用衬线体，文章用无衬线体？
- [ ] 正文字号在舒适区间（杂志≥22px，文章≥30px），行高 ≥ 1.8？
- [ ] 无 Inter 字体，无紫蓝渐变，无纯黑文字？
- [ ] 配色统一冷/暖调（不混用）？
- [ ] 图片使用 Unsplash API 获取，URL 格式正确？
- [ ] img 标签有 `onerror="this.classList.add('error-hide')"` 防破图？

## 图片策略

**图片来源**：Unsplash API（凭证在 `.env` 文件）

```bash
# 搜索图片
curl -s "https://api.unsplash.com/search/photos?query=<关键词>&per_page=1&client_id=<ACCESS_KEY>"
```

**URL 格式**（免密钥，直接引用）：
```
https://images.unsplash.com/photo-{id}?w=1080&h={h}&fit=crop&q=80
```

**图片 CSS 规范**：
- 所有 `img` 标签加 `onerror="this.classList.add('error-hide')"` 防破图
- `.error-hide { display: none }` 已在全局 CSS 声明
- 关键词：自然风景、抽象纹理、极简几何。**避免人物**。
