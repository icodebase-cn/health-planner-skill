设计理论

现代 CSS 排版设计完全指南

本文介绍现代 CSS 排版设计的七个核心原则，涵盖从基础到进阶的全部知识点。

第一原则：间距即意义

间距是信息分组的视觉语言。核心逻辑：同组内间距必须小于跨组间距，这是格式塔心理学的基本规律。

行高选择

不同场景需要不同的行高策略。下面的表格给出了推荐值：

场景推荐行高说明
日常阅读1.8–2.0最常见的舒适区间
诗歌/出版物2.0–2.5留白营造阅读节奏
技术文档1.6–1.7信息密度高，需紧凑

第二原则：视觉层次

每个元素的视觉比重必须匹配其信息层级。实现维度有五个：字号、字重、颜色、间距、装饰。

标题层级

不同层级之间视觉比重差异须清晰可感，至少用两个维度来区分。

标题层级设计检查

设计时应自问：H1 和 H2 的区别是否只用了一种手段？

设计检查提醒

H6 通常用于版权信息、注释等次要元数据。

最好的设计是看不见的设计。读者感受到的是信息，不是设计。

第三原则：数学秩序

间距和尺寸之间应有内在的数学关系，而非随机取值。

等比数列

字号层级推荐用 Perfect Fourth（1.333）作为基准比例：

:root {
  --BASESIZE: 34px;
  --H1: calc(var(--BASESIZE) * 1.333 * 1.333 * 1.333);
  --H2: calc(var(--BASESIZE) * 1.333 * 1.333);
  --H3: calc(var(--BASESIZE) * 1.333);
}

第四原则：配色系统

颜色角色定义清晰是配色系统的基础。

颜色角色

六个核心角色：bg、surface、text、muted、border、accent。

灰色规则：绝大多数场景用 1–3% 饱和度的深灰，非纯黑。

第五原则：元素渲染

列表

列表嵌套超过 3 层时，推荐字号随层级降档。

  • 第一层：Design Token 管理
  • 第二层：主题切换
    • 深色模式
    • 高对比模式
  • 第三层：响应式断点

代码块

代码块应有独立深色背景，与正文区域有明显区分。

总结

排版设计六个原则：间距、层次、数学、配色、元素、图片。记住这六点就够了。

掌握这些原则，你已经超过了大多数前端开发者。
