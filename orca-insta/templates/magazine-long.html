设计理论

CSS 排版设计的七个原则

一、间距即意义

间距是信息分组的视觉语言。核心逻辑：同组内间距小于跨组间距。这是格式塔心理学的基本规律——彼此靠近的元素被视为一组。

标题的上边距应该大于下边距，因为标题在语义上属于其后的段落。

整体偏好宽松节奏；艺术化处理时可主动压缩乃至负间距，须服务于明确的风格意图。

行高选择

不同场景需要不同的行高策略：

  • 日常阅读：1.8–2.0 倍行高
  • 诗歌/出版物：2.0–2.5 倍行高
  • 技术文档：1.6–1.7 倍行高

二、视觉层次

每个元素的视觉比重必须匹配其信息层级。实现维度有五个：字号、字重、颜色、间距、装饰。

强调只在克制使用时有效。大量的加粗等于没有强调。

标题层级

不同层级之间视觉比重差异须清晰可感。至少用两个维度来区分。

维度作用示例
字号最直接的层级信号H1 = 正文 × 2.37
字重在同一字号下的强调正文 300 / 标题 600
颜色灰度区分信息权重正文 #333 / 标签 #888

三、数学秩序

间距和尺寸之间应有内在的数学关系，而非随机取值。

等比数列：视觉张力的递进

字号层级推荐用 Perfect Fourth（1.333）作为基准比例：

:root {
  --BASESIZE: 34px;
  --H1: calc(var(--BASESIZE) * 1.333 * 1.333 * 1.333);  /* ≈ 60px */
  --H2: calc(var(--BASESIZE) * 1.333 * 1.333);           /* ≈ 45px */
  --H3: calc(var(--BASESIZE) * 1.333);                    /* ≈ 34px */
  --BODY: var(--BASESIZE);                                /* 34px */
}

避免间距出现无关联的随机数（如 17、23、37 混用），选定基准值后其他值统一推导。

最好的排版是看不见的排版——读者感受到的是信息，不是设计。
